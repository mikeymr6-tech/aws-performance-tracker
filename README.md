# AWS Performance Tracker — iPhone PWA

This is the iPhone-first version of the AWS Performance Tracker.

Features:
- Passwordless login: Name + Email are mandatory.
- Store and Set Goal.
- Rotary/telephone-style metric wheel: turn to a metric, release to log one tally.
- Nine metrics: Product Picked, Need Building, Value of Visit, Note Taking, Scheduling, Confirmation Call, Set, ND, CTS.
- Local/offline storage of the current shift.
- All-Weather Seal logo in the app.
- End Shift opens the iPhone print/save flow for a branded PDF report with the logo.

## Put it online
The files need to be hosted at an HTTPS URL before Safari can install the web app. A static host such as GitHub Pages, Netlify, Vercel, or Cloudflare Pages can host these files.

## Install on iPhone
Open the hosted URL in Safari, tap Share, choose Add to Home Screen, turn on Open as Web App, then tap Add.

## Important
The current version uses the iPhone's native print/save flow for the PDF rather than silently emailing anything. The user can save/share the resulting PDF wherever they choose.
