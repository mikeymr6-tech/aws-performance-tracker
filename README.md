# AWS Performance Tracker — iPhone PWA v2

Updated tracking interface:
- Replaced the rotary wheel with large, easy-to-hit metric buttons.
- Two-column button layout for one-handed/two-thumb use.
- Each button displays the current total.
- Tapping a metric immediately adds one tally and gives light haptic feedback when supported.
- Minus buttons remain available below for correcting mistakes.
- Passwordless Name + Email login.
- Store and Set Goal.
- All-Weather Seal logo in the app and on the generated print/PDF report.
- End Shift uses the iPhone native print/save flow rather than automatically emailing.
- Local/offline storage of the current shift.
